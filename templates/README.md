# templates · Genre template projects

**English** | [简体中文](README.zh-CN.md)

Template projects by genre: track skeletons, common instruments and effect chains, and section structures are set up in advance — open one and start creating on top of it.

One subdirectory per genre (e.g. pop, rock, electronic, folk), containing the project files and a note (intended use, track layout, sounds and presets used, license).
