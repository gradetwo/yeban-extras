# demos · Demo projects

**English** | [简体中文](README.zh-CN.md)

The eight demo projects in Yeban's startup chooser set, stored via Git LFS. One subdirectory per demo, containing only:

- The `.yeban` project file (a self-contained project container; audio the project embeds travels inside it)
- Its cover art

Loose sample folders, processing notes and other files from the original delivery packages are not stored here.

## Demos

- `雨声太吵/` — 雨声太吵. 129 BPM, 146 bars, 8 tracks. Its two guitar tracks use the system library `karoryfer-emilyguitar`.
- `潮/`, `失重/`, `呢喃/`, `失语/` — four projects on one arrangement, two vocal treatments; audio embedded.
- `下一个路口/`, `那个午后/`, `回头路/` — three folk songs. Guitar and cello use system libraries.

The project content is the author's own work; per-project details live in each project's own notes inside Yeban.
