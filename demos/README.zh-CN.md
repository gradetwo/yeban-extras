# demos · demo 工程

[English](README.md) | **简体中文**

夜半的成品 demo 包，走 Git LFS 存储。每个 zip 是按交付原样保存的完整包；解压后在夜半里打开工程即可。

## 工程包

- `雨声太吵_demo.zip` ——《雨声太吵》最终版。129 BPM、146 小节、8 轨。鼓与贝斯样本自带；两条吉他轨依赖系统音源库 `karoryfer-emilyguitar`。包内另有人声处理链文档与 A/B 试听一对。
- `雨窗四版_demo.zip` ——同一编曲的四个工程：潮、失重、呢喃、失语。两种人声处理；音频全部内嵌。
- `民谣四版_demo.zip` ——四首民谣：下一个路口、那个午后、回头路、能否。二胡与 GM 音源自带；吉他与大提琴依赖系统音源。

## 封面

`covers/` 存选择页最终 8 首的封面图：雨声太吵、潮、失重、失语、呢喃、下一个路口、回头路、那个午后。

这些包里的工程与音频内容为作者本人作品；各工程的细节见包内说明。
