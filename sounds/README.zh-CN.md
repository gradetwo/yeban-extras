# sounds · 音源与采样

[English](README.md) | **简体中文**

音源与采样库（SFZ 等格式）。一个音源一个子目录。

- 音频大文件走 Git LFS：克隆前先 `git lfs install`，否则拉到的是指针文件。
- 每个音源必须注明来源与许可；来源不明或许可不清的不要放进来。

## 下载目录

本目录的 `catalog.json` 是夜半应用读取的机器可读目录（应用主菜单里的音源管理器）。应用从 `main` 分支上该文件的 GitHub raw 地址拉取。格式见英文版 README。

规则：

- `url` 必须是包归档（zip 或 tar.gz）的直链。应用在下载后校验 `sizeBytes` 与 `sha256`，任一不符即丢弃下载。
- 同一包的 `id` 保持稳定；包内容变化时升 `version`。
- `packs` 为空是合法状态：应用会如实显示暂无可下载音源。
