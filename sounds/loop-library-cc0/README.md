# Loop Library CC0

**English** | 简体中文说明见 QA_RESULTS.md 与 SOURCES.md

49 production-ready loops from Freesound, **CC0 only**, organized by
instrument (drums, bass, guitar, piano, strings, synth, winds, harp,
keys/chords, pads, percussion). Full per-file source pages and licenses:
`SOURCES.md`. Quality gate and the 2026-11-22 gain/seam processing record:
`QA_RESULTS.md`.

## License

Every file is CC0 (public domain dedication) at its source; see

applied on 2026-11-22 do not change the license.

## Pack

`loop-library-cc0-1.0.0.zip` contains the 49 WAV files in category
folders. It is registered in `../catalog.json` for the Yeban Sound
Library manager.
