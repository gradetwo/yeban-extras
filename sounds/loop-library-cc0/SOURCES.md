Purpose: factory-content candidates for the Yeban library. Once quality-confirmed, these loops ship inside Yeban so new users can build with them immediately.

## Deliberately excluded during sourcing

- Mono uploads (e.g. radiopassiveboy tambourine loops, ondrosik beatbox loop, klcisa ambient loop, Snapper4298 strings chords) — stereo is required for factory content when stereo alternatives exist.
- Anything under CC-BY or CC-BY-NC, regardless of quality.
- Preview MP3s (lq/hq) — evaluation only, never deliverables.
- Oversized duplicate variants (holizna 192 kHz piano, 69.7 MB).
- Remix/derivative uploads (e.g. Erokia's Rhodes07 remix) — direct uploads preferred for clean factory provenance.

## factory_ready QA criteria (apply per file after download)

Set `factory_ready = yes` only if ALL hold:
1. Clean loop points: no click at the seam — check the first and last ~50 ms for a discontinuity (start/end samples near a zero crossing, or an existing short fade); audition one full loop repeat.
2. No clipping: true peak below 0 dBFS, no clipped-sample runs.
3. Loudness ballpark: integrated loudness within roughly ±3 LUFS of the batch median for its category (pads/atmosphere may sit lower by design — judge within category).
4. Technical match: decoded format/sample rate/bit depth/channels/duration match the manifest row; sha256 recorded.

Anything failing a criterion gets `factory_ready = no` with the reason noted, and stays out of the factory set until fixed or replaced.
