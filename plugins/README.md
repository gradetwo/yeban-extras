# plugins · Yeban plugins

**English** | [简体中文](README.zh-CN.md)

Plugins for Yeban. One subdirectory per plugin, with its own readme (features, installation and activation, compatible versions) and license.

Example directions: one-click publishing after a render, sharing to multiple platforms — extensions that live outside the main application.
